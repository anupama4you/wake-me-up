🚀 Quick Start: Test Geofencing in 5 Minutes
Option 1: Android Emulator (Fastest)
# 1. Start the app
flutter run

# 2. Create a test alarm
# - Search for "Pier 39, San Francisco"
# - Or manually enter coordinates: 37.8087, -122.4098
# - Set radius: 500m
# - Tap "Start Alarm"

# 3. Open Extended Controls (⋮ button on emulator)
# 4. Go to Location tab

# 5. Test sequence:
# First location (OUTSIDE - ~800m away):
Latitude:  37.8000
Longitude: -122.4098
Click "Send"

# Wait 10 seconds, watch logs...

# Second location (INSIDE - at pier):
Latitude:  37.8087
Longitude: -122.4098
Click "Send"

# 🎉 Notification should appear!
Option 2: iOS Simulator
# 1. Start the app
flutter run

# 2. Create test alarm (same as above)

# 3. In simulator:
Features → Location → Custom Location...

# 4. Test sequence:

Quick Troubleshooting
No notification?
Check permissions granted
Look for errors in console
Increase radius to 1000m
Wait 20 seconds between location changes
Service not starting?
# Check if geofencing started
# Look for this in logs:
✅ GeofenceAlarmService initialized
✅ Geofencing started for: [name]
